# TIME_SERIES_STOCK_FORECASTING
# 📊 Time Series Stock Market Forecasting Project

This project analyzes and forecasts stock market trends using time series techniques such as ARIMA, SARIMA, Prophet, and LSTM. The goal is to compare forecasting models and determine the most effective method for stock price prediction.

## 🎯 Objectives

- Understand time series patterns: trend, seasonality, noise
- Forecast stock prices using multiple models
- Evaluate model performance using MAE, RMSE, and MAPE
- Compare statistical vs deep learning models
- (Optional) Build dashboard and deploy

---

## 🧰 Tech Stack

- **Languages/Libraries:** Python, Pandas, NumPy, Scikit-learn
- **Modeling:** ARIMA, SARIMA (Statsmodels), Prophet, LSTM (TensorFlow/Keras)
- **Visualization:** Matplotlib, Seaborn, Plotly
- **Deployment:** Streamlit/Flask (optional)

## 🧪 Models Used

| Model    | Description |
|----------|-------------|
| ARIMA    | Autoregressive Integrated Moving Average |
| SARIMA   | Seasonal ARIMA |
| Prophet  | Facebook Prophet with automatic seasonality detection |
| LSTM     | Deep learning model with past sequence input |

---

## 📊 Model Evaluation

Each model is evaluated on:
- **MAE** (Mean Absolute Error)
- **RMSE** (Root Mean Squared Error)
- **MAPE** (Mean Absolute Percentage Error)

Best model is auto-selected and saved.
